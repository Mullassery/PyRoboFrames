## What Users Get

### With PyRoboFrames 2.1.0
```python
import pyroboframes as prf

# 1. Intelligent dataset selection
selector = prf.DatasetSelector()
selector.register_dataset(score)
best = selector.select_best_dataset()

# 2. Adaptive batching
sizer = prf.AdaptiveBatchSizer(min=16, max=256)
recommendation = sizer.adjust_batch_size(resources, performance)

# 3. Anomaly detection
detector = prf.AnomalyDetector()
anomaly = detector.detect_anomalies(frame_id, stats, timestamp)

# 4. Quality assessment
assessor = prf.QualityAssessor()
report = assessor.create_quality_report(name, total, anomalies, missing, consistency, sync)

# 5. Performance prediction
model = prf.PerformanceModel("v1")
model.add_training_sample(datapoint)
prediction = model.predict(batch, memory, cpu, gpu)

# 6. Autonomous decisions
engine = prf.DecisionEngine()
decision = engine.make_batch_size_decision(64, 48, 0.95, 0.85)
ranked = engine.rank_decisions_by_priority()
engine.execute_decision(ranked[0].decision_id)
```
